☁ 雲端同步（GitHub）
資料會存在你自己 GitHub 的私人 repo（data.json）。每台裝置（電腦、手機）各設定一次，之後就會自動同步。
Token 建立方式：GitHub → Fine-grained token
  1. Repository access 選 Only select repositories → 選資料 repo
  2. Permissions → Repository → Contents：Read and write
  3. 建立後複製貼到上方
Token 只會存在這台裝置上，不會出現在網站程式碼裡。
